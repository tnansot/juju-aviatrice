## Question

Sur quel intervalle le trinôme x² − 5x + 6 est-il strictement négatif ?

## Choix

- [x] ]2 ; 3[
- [ ] ]−∞ ; 2[
- [ ] ]3 ; +∞[
- [ ] Il n'est jamais négatif

## Correction

Les racines sont 2 et 3 (Δ = 1). Comme a = 1 > 0, le trinôme est du signe de a à l'extérieur des racines et du signe opposé entre elles : il est donc négatif sur ]2 ; 3[.
