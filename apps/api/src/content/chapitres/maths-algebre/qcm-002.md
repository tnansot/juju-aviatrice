## Question

Combien de solutions réelles a l'équation x² + x + 1 = 0 ?

## Choix

- [ ] Deux
- [ ] Une
- [x] Aucune
- [ ] Une infinité

## Correction

Δ = 1 − 4 = −3 < 0 : le trinôme n'a aucune racine réelle, donc l'équation n'a pas de solution dans ℝ.
