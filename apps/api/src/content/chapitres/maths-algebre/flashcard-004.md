## Question

Quel est le signe de ax² + bx + c lorsque le discriminant Δ est négatif ?

## Réponse

Le trinôme garde le signe de a sur tout ℝ.

## Correction

Quand Δ < 0, le trinôme n'a aucune racine réelle : sa parabole ne coupe jamais l'axe des abscisses et reste entièrement du même côté. Elle est donc du signe de a partout.
