## Question

Quelles sont les coordonnées du sommet de la parabole d'équation y = x² − 4x + 1 ?

## Choix

- [x] (2, −3)
- [ ] (−2, 13)
- [ ] (4, 1)
- [ ] (2, 3)

## Correction

L'abscisse du sommet est α = −b/(2a) = 4/2 = 2. On calcule l'ordonnée en remplaçant : 2² − 4×2 + 1 = 4 − 8 + 1 = −3. Le sommet est donc (2, −3).
