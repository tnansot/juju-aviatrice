## Question

Quelle est l'unité du travail d'une force ?

## Choix

- [x] Le joule (J)
- [ ] Le newton (N)
- [ ] Le watt (W)
- [ ] Le pascal (Pa)

## Correction

Le travail est une énergie : il s'exprime en joules. Le newton est l'unité de force, le watt celle de puissance et le pascal celle de pression.
