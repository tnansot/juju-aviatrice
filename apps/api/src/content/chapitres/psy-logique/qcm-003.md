## Question

Si tous les A sont B, et tous les B sont C, alors :

## Choix

- [x] Tous les A sont C
- [ ] Tous les C sont A
- [ ] Aucun A n'est C
- [ ] On ne peut rien conclure

## Correction

La relation d'inclusion se transmet : A ⊂ B et B ⊂ C entraînent A ⊂ C. L'inverse n'est pas garanti.
