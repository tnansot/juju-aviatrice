## Question

Pour f(x) = x², quel est le coefficient directeur de la tangente au point d'abscisse 3 ?

## Choix

- [x] 6
- [ ] 9
- [ ] 3
- [ ] 2

## Correction

Le coefficient directeur de la tangente au point d'abscisse a est le nombre dérivé f'(a). Ici f'(x) = 2x, donc f'(3) = 2×3 = 6.
