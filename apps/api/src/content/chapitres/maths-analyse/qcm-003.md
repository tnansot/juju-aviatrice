## Question

Quelle est la dérivée de f(x) = x·eˣ ?

## Choix

- [x] (1 + x)·eˣ
- [ ] eˣ
- [ ] x·eˣ
- [ ] eˣ + 1

## Correction

On utilise la dérivée d'un produit (uv)' = u'v + uv', avec u = x (donc u' = 1) et v = eˣ (donc v' = eˣ) : 1·eˣ + x·eˣ = (1 + x)·eˣ.
