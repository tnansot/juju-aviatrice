## Question

Comment calcule-t-on le nombre d'entités N à partir de la quantité de matière n ?

## Réponse

N = n × N_A, avec N_A ≈ 6,02 × 10²³ mol⁻¹

## Correction

Le nombre d'Avogadro N_A est le nombre d'entités contenues dans une mole. On multiplie donc la quantité de matière (en mol) par N_A pour obtenir le nombre réel d'atomes ou de molécules.
