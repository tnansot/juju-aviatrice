## Question

Quelle est la concentration molaire d'une solution contenant 0,1 mol de soluté dans 0,5 L ?

## Choix

- [x] 0,2 mol·L⁻¹
- [ ] 0,05 mol·L⁻¹
- [ ] 0,5 mol·L⁻¹
- [ ] 2 mol·L⁻¹

## Correction

On applique c = n/V = 0,1 / 0,5 = 0,2 mol·L⁻¹.
